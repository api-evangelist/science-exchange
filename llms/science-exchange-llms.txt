# Science Exchange

> Science Exchange is an R&D supplier orchestration and procurement platform for life-sciences organizations, running a marketplace of 3,800+ pre-qualified scientific service providers under a single master service agreement. It exposes a read-only Providers REST API (v1) that lets scientific-service suppliers pull their RFQs, quotes, services, facilities, line items, ratings, tags, and users.

- Website: https://www.scienceexchange.com
- Backed by: a16z, Index Ventures, Union Square Ventures
- Founded: 2011 (Palo Alto, California)

## APIs

- [Science Exchange Providers API](https://demo.scienceexchange.com/api-docs/providers): Read-only REST API (v1) for scientific-service providers. Base URL https://www.scienceexchange.com/api/providers/v1 . Auth via access_token query parameter.
